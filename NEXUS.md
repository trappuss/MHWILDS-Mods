# Posting a mod on Nexus Mods

Nexus Mods descriptions use BBCode (Bulletin Board Code), not Markdown. A README from this
repository has to be converted before it is pasted into a mod page.

The site has a rich text (WYSIWYG) editor with a button that switches to the BBCode view.

| Tag | Use |
| --- | --- |
| `[b]` | Bold |
| `[i]` | Italics |
| `[url=...]` | Links |
| `[list]` and `[*]` | Lists |
| `[code]` | Code blocks |
| `[spoiler]` | Hidden dropdown sections |

Standard BBCode has no headers like Markdown does. Headings are made with sized text tags
or the editor's built-in header styles.

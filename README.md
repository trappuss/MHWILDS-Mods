# MHWILDS-Mods

Mods for Monster Hunter Wilds. Each mod lives in its own folder with its own README.

## Catalogue

| Mod | What it does | Version | Requires |
| --- | --- | --- | --- |
| [MenusEverywhere](MenusEverywhere/) | Opens the facility menus (Item Box, Smithy, Artian weapons, shop, Melding Pot, Smelting Foundry, village trade, Support Desk, camp and lobby tools) from the pause menu, camp menus or your handler. One folder row per facility, presets per menu, everything toggleable. | 1.1.0 | [REFramework](https://github.com/praydog/REFramework-nightly/releases) |

## Installing a mod

Open the mod's folder and follow its README. Unless it says otherwise, copy the `reframework`
folder inside it into the game folder (next to `MonsterHunterWilds.exe`).

## Adding a mod to this repository

1. Put it in a new folder at the top level, with a `README.md` inside.
2. Add a row to the catalogue above: name linked to the folder, a one or two sentence
   description, version, and what it requires.
